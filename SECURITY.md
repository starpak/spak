# Security Policy 🔒

> The Spak project takes security issues seriously. If you discover a security vulnerability, please report it as described below.

> **中文版**: [SECURITY.zh.md](SECURITY.zh.md)

---

## 🐱 Supported Versions

| Version | Supported |
|---------|:---------:|
| Latest  | ✅ Yes |

We only provide security support for the latest release. Please make sure you are using the latest version.

## 🚨 Reporting a Security Vulnerability

**Please do not report security vulnerabilities through public GitHub issues!** Public discussion of security vulnerabilities could be exploited by malicious actors.

### How to Report

Please report security vulnerabilities privately through one of these channels:

1. **Send an email to:** security@spakjs.org (or use GitHub Security Advisory below)
2. **Or via GitHub Security Advisory:** Click `Security` → `Report a vulnerability` on the repository page

### Information We'd Like

- Type and severity of the vulnerability
- Full path to the affected component
- Detailed steps to reproduce (PoC is even better!)
- Potential impact and suggested fix

### What We'll Do

| Step | Timeframe |
|:----:|:---------:|
| 🟢 Acknowledge receipt | Within 48 hours |
| 🟡 Assess impact | Within 5 business days |
| 🟠 Release fix | As soon as possible after assessment |
| 🔵 Public disclosure | After the fix is released |

We will keep you informed during the assessment and fix process. Please keep the vulnerability information confidential until the fix is released.
